EV9V classRecordingsShare of testA08 precisionA08 recallA08 F1STFM F1

A08 values average the three frozen seeds; STFM uses its native rule. Accuracy = correctly classified recordings / all recordings. Precision = correct predictions of a class / all predictions of that class. Recall = correct predictions of a class / all true recordings of that class. F1 = 2 × precision × recall / (precision + recall). Macro-F1 averages the five class F1 scores with equal weight, so each class contributes 20%, even when it is rare.
