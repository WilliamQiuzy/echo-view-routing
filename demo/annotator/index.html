标注说明 Instructions

每段录像只看图像本身，不要猜测来源或用途。录像顺序已随机，编号不含任何信息。
Judge each clip from the images only. Order is random and IDs carry no information.

  1. 先以 1× 完整看一遍，再用 0.5× 或逐帧查看。
    Watch once at 1×, then at 0.5× or frame by frame.
  2. 回答问题 1：图像是否显示切面变成了另一个切面。只按图像判断，不需要判断探头是否移动。
    Answer question 1: do the images show a change to a different view? Judge from the images; you do not need to decide whether the probe moved.
  3. 标注区间：用 [ ] 设起点和终点，再点类型。
    Mark intervals: set start and end with [ ], then click a type.
    • A 切面改变：起点 = 旧切面最后一个清楚的帧，终点 = 新切面第一个清楚的帧（中间为过渡）。突变时起点 = 终点。填写改变前后的切面。
      View change: start = last frame clearly in the old view, end = first frame clearly in the new view (the frames between are the transition). For an abrupt change, start = end. Give the views before and after.
    • B 同一切面、局部证据不足：切面没有变，但这些帧里辨认该切面所需的结构看不到或看不清（例如某些时相结构消失、声影、伪像）。如随心动周期反复出现，请勾选。
      Same view, locally insufficient evidence: the view has not changed, but in these frames the structures that identify it are not visible (e.g. lost in some phases, shadowing, artefact). Tick if it recurs with the cardiac cycle.
    • C 无法判断：无法确定是切面改变还是证据不足，或者拿不准。允许不确定，拿不准时请选 C。
      Undeterminable: you cannot tell which of the two it is, or you are unsure. Uncertainty is allowed; choose C rather than forcing A or B.
  4. 图像仍是同一切面、只有轻微晃动时，不算切面改变。整段清楚、无改变的录像：问题 1 选"否"，不标区间。
    Slight movement within one view is not a change. A clear clip with no change: answer "No" and mark nothing.
  5. 结果自动保存在本浏览器；完成后点"导出"，把 JSON 文件发回。
    Work autosaves in this browser; when finished click Export and send back the JSON file.
