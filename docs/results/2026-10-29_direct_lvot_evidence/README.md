## Why the source was not admitted

The Demo explicitly links its named annotation to B-mode data and a sector-owned point array. The main exporter instead labels `annotations/measurement_000_points` as a spatial LVOT caliper with a **global** target. A global label alone was insufficient. Before main array decoding, the reviewed clarification required a unique endpoint match to an explicitly owned overlay in the recording's sole static tissue B-mode sector, preserving the original global link and derived join separately. None passed.

Full publisher archive hashes and independent decoding make a simple incomplete transfer or alternate decoder an inadequate explanation for the observed mismatch. They do not prove corrupt data, erroneous anatomy or a specific exporter defect. The coordinate/frame-binding semantics remain unresolved for this protocol. No axis swap, sign/offset adjustment, nearest frame, metadata-over-array substitution or inferred A4C absence was used to manufacture admission. The old undocumented `data_sha256` semantics remain unresolved; raw-array hash inequality alone is not called corruption or used as the new integrity contract.
