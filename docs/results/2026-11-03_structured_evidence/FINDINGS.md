# A58研究结论与证据缺口

A58已经完成8个头、48000次正式优化更新、24个inner checkpoint读出、72项外层指标以及132组预先声明的配对bootstrap比较。**固定6000步主任务上，D0/D1/D2/D3两个head seed的原生macroF1和multi片段F1都低于冻结的原A08-s0+B3。论文目标尚未达到。** 外层结果没有改变模型、阈值、系数、训练步数或选择规则。资源/进程终账与主工作区同步另行完成后才关闭本轮监控；没有自动A59。

本轮问题是：保留A08识别分数，在精确条件NLL训练和相同分数MAP推理中加入JEPA概率轨迹，能否提升分段且保留识别和真实短段？D1/D2使用同一A08 unary、4894参数、共同初态/计划和两个seed；D2−D1是主比较。D0只固定显式end-duration表g为0，仍保留学习转移（含stay势能）；D3为JEPA-only。两视觉生产者完全冻结，D2不是latent解剖特征融合。

A58新增确认了哪些问题：

- **当前概率轨迹包会损害稳定识别。** 同一A08 unary下，D1 selection A5C为10/11，D2为7/11，原A08为11/11；D2原生macroF1为.930765。这说明“冻结好unary”并不保证联合解码保留它的正确决策。它不证明JEPA预训练、架构或临床解剖机制是原因，轨迹包还含上下文/采样相位等差异。
- **少假切不能替代保留真实变化。** D1 selection假短≤16位置FP由A08的9降为6，但真实短段FN由7/141升至18/141，边界召回由.965969降为.939791。D0有相同的原生错误及短段FN，D1−D0片段变化很小且随seed改变。因此显式duration表不是唯一解释；D0仍含学习stay势能，不能据此排除所有持续时间偏好。
- **增加输出采样密度不足以解决主任务。** 同一A08-s0从原stride5+B3改为stride2并原样转移B3，selection片段F1 .956349→.954545，calibration .982692→.978846，原生macroF1相同。此控制没有分离采样相位/上下文，也不能把所有时间分辨率假说一并否定。
- **内层选择没有救回外层目标。** seed358的D2按冻结inner规则选择step2000，外层片段F1为.907646/.969815，仍低于A08 .956349/.982692；其余所有selected行照录。固定6000和inner-selected没有混成一张“最优”表，也没有按outer挑checkpoint。

必须同时保留的正结果是**时长分布改变后的局部恢复**。事先冻结的0.4–8秒stress bank每半部另抽120条multi流，来源仍来自已使用开发数据；原生和pair预测与主表完全相同，不是新样本。calibration的D2片段F1 .956183/.955166，高于原A08 .923541：+3.26个百分点[+1.45,+5.17]及+3.16[+1.14,+5.19]。真实短段FN为23/159，对A08 54/159，假短FP均2。D2也显著优于该stress上的D1，说明新轨迹在这一构造条件下有可用信息，不能把本轮写成“JEPA没有任何价值”。

这个增量没有成为全任务胜出：stress selection的D2相对A08为−.003604/−.002268，区间都跨0；真实短段FN虽从79/201降为38/201及36/201，假短FP却从19升为27/28，原生A5C损害完全保留。D3同样有局部stress增益，所有负/正结果均报告。stress同时改变了长度支持及新构造bank，不能称同一批流的纯时长因果干预，更不能称连续临床扫描验证。

训练执行证据与性能证据分开。严格400-key A08/214-key JEPA源、真实完整序列图/梯度/resume、原子journal/Adam实际计数及51项最终focused检查通过；60+144次工程更新另计，未混入48000正式更新。八头所有活跃参数有梯度/矩/漂移证据，未发生静默重放。480个固定100-update训练bin及24个inner点见[training_curves.csv](training_curves.csv)、[inner_curves.csv](inner_curves.csv)。bin是不同FIT样本的等update平均，NLL不是IoU/F1，也不是held-out损失；这些曲线不能证明充分收敛或解释外层退化的唯一原因。

剩余未解决的是如何在保留A08可靠识别的同时，只利用能改善真实短段/变化的信息。A58否定的是当前不受识别保护约束的posterior轨迹联合解码配置；没有测试latent特征、可见性监督或带明确识别保护的决策机制。今后若另行授权新轮，研究动因应来自已保存的恢复/损害及短段分布，而不是再次盲目扩大骨干或调整平滑阈值；应先冻结可证伪的识别保护与边界恢复条件，再做匹配对照。本段是后续研究动因，不是新实验准入或自动执行计划。

论文证据缺口仍在：A08历史见过部分inner来源；所有开发半部重复使用，session不是确认患者；clip标签传播不等于逐帧可见性，拼接变化不等于真实扫查。用户目前没有人工标注资源，[独立标注协议](annotation_protocol.md)仍未执行。本轮不能宣称独立临床验证、解剖机制证据或达到论文目标。
