# A26：冻结模型在历史 EV9V test 上与外部方法同场比较（2026-10-23）

**问题。** 在同一份历史 EV9V test benchmark 上，比较以下几组系统，并看 A14 相对 A08 的局部收益是否仍在。benchmark 即 H09 修正后的五类识别和构造流切分。
- 我方系统是冻结的 A14 P 局部路由（seed 0、2），以及同 seed 的冻结 A08 + B3。
- 外部系统是已实现的 STFM、ASFormer、EchoPrime（逐帧，以及验证集选定的 B3）和 EchoViewCLIP stage 1。

**性质和边界。**
- 这是冻结系统的同 benchmark 探索性复现比较。没有任何训练、调参、阈值重选、seed 或 checkpoint 挑选，也没有新增候选。
- 它不是独立 holdout：H01–H09 用过这份 test。它也不对应各原论文的九类或其他任务。
- 本轮读取旧 test 经负责人和用户 2026-10-22 明确授权。Pediatric 未读。
- 配置和模型注册表在任何本轮 test 读取之前提交（a74b2e1）。访问记录写于 2026-10-23T03:11:22Z（`runs/frozen_external_benchmark_v1/access.jsonl`），此后才建立 benchmark manifest。
