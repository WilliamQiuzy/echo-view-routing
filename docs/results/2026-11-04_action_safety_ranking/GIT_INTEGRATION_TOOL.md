# Narrow A61 public-path commit tool

`scripts/commit_action_safety_paths.py` is an administrative helper, not a research dependency or an execution queue. It never copies payloads or edits `docs/EXPERIMENT_INDEX.md`, shared exclude/config files, or unrelated working files. Implementation/tests have not run it against real main. Only isolated temporary repositories are exercised.

Default invocation is a dry-run. Supply an explicit repository root, exact expected40-character HEAD, attached `refs/heads/...` branch, commit message, and a JSON list of newly copied A61 paths with expected SHA256s. Optional `mode` pins are100644/100755. Allowed paths are limited to the new A61 public directory, A61 config/plan, and new safety code/test filenames. Every target must be a regular file absent from both HEAD and every original index stage. Original bytes must match the reviewed pins. No already tracked A61 path can be changed with this tool.

The dry-run creates objects and two indexes only in a temporary quarantine. The commit index is seeded from HEAD, excluding every original user-staged change; its final tree diff must consist solely of additions of the explicit copyset. The preserved index starts from the original index and adds exactly the same new entries. Every existing entry's complete serialized stat/flags/mode/OID/path bytes must remain identical. The tool currently supports ordinary full index versions2/3; split/sparse/version4 and active merge/rebase/sequencer states reject rather than convert or repair user state.

To apply, explicitly add `--apply --expected-index-sha256 DIGEST`, using the dry-run's original-index digest. Use the normalized per-path mode/SHA pins from the reviewed plan. The helper rechecks attached branch, HEAD, original index and payloads, holds `index.lock`, and uses Git's prepared expected-old transaction on the actual branch. On the qualified Git2.54 backend, that transaction also locks attached HEAD; the helper requires the HEAD lock before publishing and refuses unsupported behavior. Git hooks are disabled for this one invocation; no repository config is edited. Commands have10-second bounds and the operation has a120-second bound.

There is **no cross-crash atomic swap of a Git ref and index**. A durable new intent and private original-index backup are written before publication. With the prepared ref transaction still locked, the validated preserved index is atomically replaced while the tool's separate index-lock marker remains held. The expected-old ref transaction is then committed. Success requires observed final branch/HEAD/index agreement before the owned index marker is removed. Standard Git writers are blocked through the critical section. The helper never force-updates, rolls back or replaces a changed concurrent index/HEAD.

Returned states are `dry_run`, `applied`, `rejected`, or `partial`. Publication flags distinguish index from target-branch publication, including if HEAD changes after the branch commit. On a partial failure/crash, inspect the recorded intent, actual target branch, index digest and private backup; the tool retains its index marker and does not automatically recover or generically delete lock files. Git may release its own prepared HEAD/branch locks on abort. Unreachable promoted objects may remain after an aborted apply; this is disclosed administrative object storage, not a published commit. The private intent/backup are Git metadata and must not enter a public payload manifest.

Toy fixtures cover exact new-file-only commits with eight unrelated staged additions plus a separate staged/unstaged edit and unchanged user index document; dry-run object/index/ref immutability; an unusable exclude file; occupied locks and stale HEAD/index refusal; an injected failure between index/ref publication; and an observed concurrent HEAD move after target-branch publication. Initial missing-module and real protocol failures are retained with their OS statuses/actual CPU receipts. Some early receipts have intended `GREEN` stage names but nonzero observed OS status; they remain failed attempts, not passing evidence. No old research tests, model/source forward or SSH was run for this tool.
