# A61残余错帧：两个案例、三层瓶颈

结论：这两个失败首先暴露**该保持A08时仍决定修改、收益符号判错、风险证据误放行**，不是“已有正确候选却只差换一个排序损失”。两例的G内非空候选均不安全，事后正确决策都是no-op。候选语法的局部安全容量也有限，尤其JEPA整run不能把两处有益修复与中间被破坏的A5C分开。下一轮应先检验动作级拒绝及锚点上下文，再决定是否扩候选；方案见[NEXT_ROUND_PROPOSAL.md](NEXT_ROUND_PROPOSAL.md)。**未启动A62。**

这是A61结题后的只读事后诊断。原模型、阈值、314/240/60/56结果、资源快照及Git封存不变。两次小型服务器诊断均实际OS0，0神经前向、0优化器更新。原始ID、逐位置数组、完整候选特征留服务器；本目录只有匿名统计与可复现方法。

## 先分清动作和bank

H为原A08正确而修改后错误的位置，R为原错被修复的位置，净错帧变化为H−R。位置沿用A61的原参考轴，不换算为独立采集帧数或临床秒数。以下均相对传播的clip-family参考标签，尚无专家逐帧可见性标注。

| 范围 | 危险动作自身H/R | 整个120流bank的H/R | 解释 |
|---|---:|---:|---|
| 旧A60构造selection，S-L-C seed461 | 40/0 | 40/37，净+3 | 37个修复全来自其他动作；此危险动作本身毫无修复 |
| 新A61构造outer-calibration，seed461 | 9/2，净+7 | 9/35，净−26 | 其他动作修复33；bank净好转掩盖此动作损害 |
| 同一新A61轴、同一动作，seed462 | 9/2，净+7 | 9/20，净−11 | 其他动作修复18；不是另一条独立失败病例 |

这里只算相应multi bank。它不混入复用的native/pair修复。outer-calibration是外层另一半的历史名称，**不是928轴inner阈值校准集**。

## Case A：正确PLAX前缀被“修复”为PSAX

- 整轴长146，Base预测为单个PLAX run。接受的是**旧raw-A08分歧动作**，不是JEPA独有动作。
- 动作改前缀40个位置，40个均为参考PLAX、Base也为PLAX，修改后全成PSAX：H40/R0。动作内部及端点均无参考真变化。
- 预测从`PLAX×146`变为`PSAX×40 | PLAX×106`，新增1个错误边界。它是新造错误前缀，不是延长旧错段，也不是“少切”案例。
- 匹配真段数ΔM=0，预测段数ΔP=+1，短FN/FP均不变。新错PSAX段长40，短FP≤16指标看不见它。

固定FIT操作点F=.8917446116下，真实u=2ΔM−FΔP=−.8917446，安全目标v=−1−|u|=−1.8917446；模型却给**+2.470798**。这两个目标本来都不奖励该动作，问题在预测符号，不是目标缺少惩罚。

风险模型预测H=.042540、R=39.942624，把几乎整段“新增错误”认成“修复”。pFP=.001566；r=.003206低于τ=.007963，N和C都放行。r严格大于pFP，而代码定义r=max(max位置pH,pFP)，所以可精确反推max位置pH=.003206。不是某个高危险位置被平均掉；模型没有给任何位置高H证据。

40个H位置的平均`P(拟改类)−P(Base类)`：raw A08为+.8533，JEPA为+.9919。两个producer都高置信支持PSAX，但B3锚点保留了参考正确的PLAX。B3是JSD分段后按整段均值赋类；局部raw置信度和双源一致并不能自动推翻这个更长上下文的决定。标签传播也可能与局部可见性不同，当前没有影像专家核验，不能据此宣布解剖学真错或真对。

该轴G内有2个候选，**真正H0且不增短FP的候选为0**；按真实u/v排序连固定0分no-op也胜不过。不能通过在这两个候选间重排找出安全修复。

## Case B：JEPA整run跨掉短段，连正确类也丢匹配

两seed接受的是同一条轴、同一个JEPA动作。整轴66，canonical动作跨度46，其中35个位置本来已经A4C，实际只修改11个位置：

- 9个正确A5C被改成A4C，H9。
- 1个参考A4C、Base为A5C的位置修复；另1个参考A4C、Base为SC4C的位置修复，R2。
- 动作跨2个参考真变化。按已存run长度可还原预测变化：

```text
Base： A4C×10 | A5C×10 | A4C×35 | SC4C×11
修改： A4C×56                     | SC4C×10
```

删除3个旧预测边界，新建1个右端边界，ΔP=−2。丢失匹配的两条真短段分别为**A4C长11、A5C长9**，不是两个A5C段。A4C颜色虽仍正确，合成56长预测段后，11长真段即使完全被覆盖，IoU也至多11/56≈.196，小于.5，因此仍会丢匹配。

动作ΔM=−2，真实u=−4+2F=−2.2165108，v=−3.2165108；短FN+2、短FP不变。少2个预测段并未带来正确短段恢复，反而吞掉已有匹配。

| 主方案同一动作 | seed461 | seed462 |
|---|---:|---:|
| 预测安全收益 | +2.242039 | +1.124531 |
| 预测H / 实际H | .046366 / 9 | .054203 / 9 |
| 预测R / 实际R | 10.905705 / 2 | 10.931224 / 2 |
| pFP | .000000304 | .000013072 |
| r=max位置pH（因r>pFP） | .004703930 | .006327166 |
| 冻结τ | .007963287 | .006616456 |
| τ−r | .003259357 | .000289290 |

这次raw A08在9个H位置仍支持Base：`P(A4C)−P(A5C)`平均−.5259；JEPA却强推A4C，平均+.9529。现有特征包含这个冲突，风险模型仍把约11个修改几乎全算为修复。不能只用“缺少A08证据”解释；证据的上下文表示、训练泛化与拒绝目标需要分开试验。

该轴G内只有1个非空候选，且不安全，没有既修2个位置又保留中间A5C/短段的原语法候选。此处不存在多个非空动作的排序问题；主要错误是它战胜了no-op。

## 匹配控制说明了什么

检查了两条独立轴各8个utility配置，即16个不同axis×arm输出。匿名原件保存3个primary接受记录，因此Case B的8臂会重复出现两次；不能算作24个独立控制。

| 案例/风险seed | U-P C | U-L C | S-P C | S-L C |
|---|---|---|---|---|
| A，461 | 接受 | 接受 | 接受 | 接受 |
| A，462 | 拒绝 | 拒绝 | 拒绝 | 拒绝 |
| B，461 | 接受 | 接受 | 接受 | 接受 |
| B，462 | 拒绝 | 拒绝 | 接受 | 接受 |

所有16个E和N均接受同一危险动作。B的462四臂共享同一个风险r=.006327：U-P/U-L的τ=.005670而S-P/S-L的τ=.006616，所以C差异来自阈值，不是安全收益臂在这个案例找到了更好的候选。各臂τ由各自inner top选择产生，不能把C之后U/S差异全部归为utility效果。

A61已经有固定0分no-op，L损失也已经纳入no-op比较，v已经将unsafe置负；再说“加no-op、加排序或惩罚H”不是新的实质方案。全矩阵20个隔离listwise效应的区间包含0，也不支持先扩大排序损失。

## 归因判断与反事实边界

| 层面 | 两个案例的证据 | 判断 |
|---|---|---|
| 候选内排序 | A仅2候选、B仅1；所有安全非空候选数为0 | 不是漏选了一个已经存在的好动作；不能靠非空候选重排解决 |
| 收益估计/拒绝 | 真实u和v均负，8臂却均给正分，战胜no-op | 明确的价值符号及外层拒绝泛化错误；不同于证明pairwise损失未执行 |
| 风险模型 | H几乎被解释成R；最大位置pH也很低；FP头看不见FN丢失 | 是直接的防线失败；不是仅靠均值聚合造成，也不是只有阈值略松 |

## 模型机制的已知与未知

47维位置风险输入是当前A/J概率、Base/拟改类、左右各16邻域的概率均值及几何坐标；109维候选输入主要为动作/两侧窗口的概率与占比统计。它们不保留完整时序，也没有显式完整B3段支持度。Case A会丢失长146段的整体证据；Case B的46跨度及中间35个不变位置，被压缩为统计量后可能掩盖跨run的合并后果。这是有代码和案例支持的**待检验表示假设**，不是已证明的根因。

训练风险CE先对每个动作的全部changed positions取均值，再对动作平均。它学习逐位置H/R/neutral；推理N检查预计H−R≤0，C再用max位置pH/短FP证据。N保护的是预测净效果，maxpH也不是“至少一个H”的动作概率。下一轮应直接检验动作级unsafe事件，而非把maxpH当成事件置信度。

旧bank seed461最低证据箱[0,.2)含157候选、25个unsafe，实际H总114而预计H总16.27；新bank对应172候选、26个unsafe，实际H50而预计15.17。这支持低风险区域的错误不止一个。候选和来源相关，这不是独立概率校准检验，不能直接用unsafe比例减平均r计算事件概率ECE。

FIT曾有H最高43、changed K最高51，所以H40/K40和H9/K11并非仅因超出已知长度/危害范围。匿名报告给出部分标准化特征较极端（A位置最大|z|≈9.44），但没有密度、近邻与标签覆盖审计，不能凭max-z宣布OOD。逐位置pH向量没有保存；本次只利用已存sum及r关系，没有补跑网络伪装为缓存值。
