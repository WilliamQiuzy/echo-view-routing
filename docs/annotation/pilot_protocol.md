## 目的

检验 H1：专家能否在真实录像中区分两种情况——

- **切面改变**；
- **同一切面，但当前帧不足以辨认**。

本试点只估计可行性和一致性，不设成败门槛。

## 材料

- EV9V 验证集和测试集中的原生录像。每段是一次独立存储，不做拼接。
- 帧按真实时间顺序导出。共享缓存的帧顺序有误，见 `docs/results/2026-09-30_realvideo_round1/`。
- 排除发现集 7 段：6 段难判的 A5C，以及 1 段疑似标签错误的 A4C。这 7 段只用于形成假设。
- 由 `scripts/export_annotation_pilot.py` 生成（种子 20260930），每个推定患者分组最多 2 段。
- **推定患者分组。** 分组由 `patient_of()` 得到，即去掉 video_id 的最后一段。分组数（703）恰好等于 EV9V 论文报告的患者数，这只是线索，不能证明每组就是一名患者。在得到数据来源方的确认之前，所有"患者"都应写作"推定患者分组"，分析中也要说明这一限制。
- **已用于探索。** 这批录像已经用于候选筛选、阈值设定和任务定义，以后不能当作未经接触的最终测试集。

1. 读者必须具备 PhysioNet 资质并签署 DUA。
2. 每个 MIMIC 文件是 1–3 个心动周期的 ECG 门控循环，循环内几乎不会发生切面改变。

## 盲法

- 读者包只含随机编号、帧和帧率。没有标签、模型输出、入选原因或分层信息。
- 片段顺序随机。重复片段换新编号，且与第一次出现至少间隔 20 段。
- 钥匙文件 `key/pilot_key.csv`（编号对应的来源、分层和筛选分数）由研究者单独保存。
- 读者之间互不交流，也看不到彼此的结果。

## 读者与标注内容

至少需要 2 名独立读者（心脏超声医师或技师），可另加 1 名提供第三意见。每段录像分层标注：

1. **片段级。** 切面是否改变（是／否／无法判断）、置信度（1–3），以及主要切面（可选）。
2. **区间级。**
   - **A 切面改变。** 允许过渡区间，需填写改变前后的切面。
   - **B 同一切面、局部证据不足。** 可勾选"随心动周期反复"。
   - **C 无法判断。**
3. **备注。**

导出的 JSON 同时记录帧号和秒数。

## 分析计划（事先写定）

**读者间一致性**

| 指标 | 计算方法 |
|---|---|
| 片段级一致性 | 两名读者用 Cohen κ，三名及以上用 Fleiss κ；按患者做 bootstrap，给出 95% CI；按层分别报告 |
| 阳性一致性 | 对"切面改变"和"有 B 区间"分别报告阳性一致性（2a / (2a + b + c)），因为 κ 在阳性很少时不稳定 |
| 不一致的片段 | 一名读者标出改变、另一名没有标出的片段数量和比例，逐例列出 |
| 改变时间 | 至少一名读者标了 A 的全部片段都纳入：两人都标时比较 A 区间中点的差（秒）和 IoU，只有一人标时 IoU 记为 0 并单独计数。不能只在两人都标出的片段里比较边界 |
| B 区间重叠 | 至少一名读者标了 B 的片段，两名读者 B 区间的帧级 IoU（只有一人标时记为 0） |
| 不确定比例 | 问题 1 选"无法判断"的片段比例，以及被标为 C 的时长比例 |
| 重测一致性 | 8 个重复片段中，同一读者两次结果是否一致 |

**发生率（只用随机层）**

- 报告"切面改变"和"有 B 区间"的比例，用 Wilson 95% CI。随机层每段来自不同的推定患者分组，可以视为独立样本。
- 这个比例的含义要写清楚。因为是先抽分组、再抽一段，它是"每个分组随机取一段录像"时的比例。它不直接等于全部录像中的发生率（录像多的分组在其中权重偏低），也不等于"某个分组至少出现一次该现象"的比例。如需全部录像的发生率，应按分组的录像数加权（逆抽样概率）。
- 30 段的置信区间很宽，例如 3/30 为 3.5%–25.6%，0/30 为 0–11.4%，只能说明量级。
- 候选层中的比例不代表真实发生率。

**不设成败门槛**

不使用"10%"这类门槛：即使 100 段中有 10 段阳性，Wilson 95% CI 也有 5.5%–17.4%。

## 本轮之后

- **H1 成立的条件：** 片段级一致性（κ 和阳性一致性）和 B 区间重叠都能被不同读者重复出来，不一致片段和不确定比例都不高。
- **如果成立：** 第二轮检验 H2，即相位对应是否在平滑、置信度和持续时长之外提供新的信息。
- **如果不成立：** 先改进标注定义（例如把过渡单列为一类），再谈建模。
