# 切面标注试点：读者说明

**Reader instructions for the view annotation pilot**

## 开始

1. 解压文件夹，用 Chrome、Edge 或 Safari 打开 `index.html`，不需要联网。
2. 第一次打开时输入读者编号，例如 `R1`。
3. 共 95 段超声心动图录像，其中前 2 段是练习，不计分。

关于录像：

- 顺序是随机的，编号不含任何信息。
- 不提供原始标签、模型结果或入选原因。请只根据图像判断。
- 屏幕上的机器文字（如增益、多普勒设置）属于原始录像。请按解剖结构判断，不要依据这些文字。

## 每段录像怎么做

1. 先以 1× 完整看一遍，再用 0.5× 或逐帧查看（`←` `→`；按住 `Shift` 一次跳 10 帧）。
2. **问题 1：图像是否显示切面变成了另一个切面？** 选是、否或无法判断。只根据图像判断，不需要判断这种变化是否由探头移动引起。
3. **标区间：** 用 `[` 设起点、`]` 设终点，再点类型：
   - **A 切面改变。** 图像支持切面已经变成另一个切面（如 A4C→A5C、PLAX→PSAX），或已经离开标准切面。
     - 起点是旧切面最后一个清楚的帧，终点是新切面第一个清楚的帧，两者之间是过渡。
     - 突然改变时，起点等于终点。
     - 请填写改变前、后的切面。
   - **B 同一切面，局部证据不足。** 图像支持切面没有改变，但这些帧里辨认该切面所需的结构暂时看不到或看不清。例如：
     - 某些时相里左室流出道或主动脉瓣不显示；
     - 声影或伪像遮挡。

     如果这种情况随心跳规律反复出现，请勾选"随心动周期反复"。
   - **C 无法判断。** 分不清是 A 还是 B，或者拿不准。允许不确定；拿不准时请选 C，不要勉强归为 A 或 B。
4. 选择整体把握（低、中、高）。主要切面和备注可以不填。
5. 点"完成并下一个"。

## 什么不算切面改变

- 调增益、深度或缩放；
- 图像仍是同一切面，只有轻微晃动。

**特殊情况：**

- 整段清楚、没有改变：问题 1 选"否"，不标区间。
- 整段都看不清：问题 1 选"无法判断"，可以把整段标为 C。

## 其他

- 请独立完成，不与其他读者讨论。
- 可以分几次完成，进度自动保存在当前浏览器里。
- 完成后点"导出"，把生成的 JSON 文件发回。
- 换电脑时，在新电脑上"导入"上次导出的文件。
- 预计每段 1–2 分钟，总共约 2–3 小时。
- 录像来自公开数据集 EV9V（CC BY 4.0）。请不要另行传播这个读者包。
