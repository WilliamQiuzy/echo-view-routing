## 1. 这次真正改变什么

用户指出的问题有依据，但不能把历史解释成“没有真正训练”：A41 有四个900步 LoRA 模型，A55 有四个3600步全模型，A56 有两个1200步全模型。问题主要是研究空间越来越局部，而非所有实验都只训练了一个小头。

| 过去的限制 | 本轮的替代方式 | 仍需保持的边界 |
|---|---|---|
| 先通过10名复用源患者上的硬性误报门槛，才准许目标任务实验 | 源表现作为诊断；候选直接在声明的目标开发协议上评估 | 旧轮失败结果不变；不把源表现叫作目标提升 |
| 只改 Base-A4C，或只给 A08 的固定区间重新命名 | 输出整条五类时间轴，允许新增、移动、删除预测边界 | 不利用真切点/来源身份参与推理 |
| 反复依赖512维投影、局部概率或固定窗口汇总 | 从未投影的稠密时空 token 建立长序列表示 | 512维不是已经证明的原因，token 注意力也不是解剖标注 |
| 单一学习率/短训练配方失败后立即关闭 | 小规模并行配方探索、预先声明的逐级算力分配、充分训练幸存配置 | 不用最终测试挑学习率，不反向改写已完成实验 |
| 研究中间阶段要求所有指标同时达到最终采用标准 | 展示分段、原生识别、边界、短段和逐类错误的 Pareto 权衡 | 发布/采用仍要求完整系统结果和独立验证 |
| 每个小轮次重复全套审计/资源上限把协调墙钟当训练成本 | 复用已验证管线；只重点验证新权重、新图和新时间对齐 | 保留身份、有限梯度、实际更新、恢复及冻结后评估证据 |

A01 只训练冻结视频特征上的 MS-TCN/ASRF；A10/A11 已经训练过边界头，不能称“首次边界学习”；A41 已经试过旧 EchoJEPA 的 LoRA。新条件是**稠密 token → 较长时间序列 → 完整五类预测，并把序列误差反传到视觉骨干**。A55/A56 的同批外部患者源任务不再充当唯一入口。

## 3. 第一组可直接运行的比较

固定参考：原 A08+B3，保持原权重与相应评价定义；不把它当作教师强制新模型保持同样错误。

| Arm | 相同输入/空间汇总 | 时间模块 | 骨干更新 | 主要用途 |
|---|---|---|---|---|
| L | 新骨干最终层稠密 token | 逐时刻线性五类读出 | 冻结 | 同一表征的简单局部基线 |
| F | 同 L | 长序列轻量 TCN | 冻结 | 完整序列模型的冻结视觉对照 |
| J-low / J-high | 同 L/F | 与 F 同一 TCN | 全骨干 | 检验联合视觉学习；两个预定学习率探索 |

J−F 是主要视觉联合学习对照。F−L 是完整时间模块包的比较，参数容量同时不同，不能单独宣称“时间顺序的因果贡献”。若需要机制主张，再做相同容量的局部注意范围/顺序扰动消融，不把所有变化一次打包。

初始输入为64个真实10Hz采样位置（约6.4秒），按四个16帧短块通过同一个视觉骨干，输出每块8个tubelet位置的稠密特征。先固定空间平均，得到32个时间位置的未投影特征；避免把64帧的所有空间 token 一次送入巨大的全局注意力。多层/多查询空间池化、双速率和128帧支持是后续明确消融，不混入首轮。

**时间对齐必须成为可执行合同：**固定tubelet覆盖、中心、末端padding/mask、32→64时间轴映射及重叠块拼接。训练只读本训练分区的原图和公开标签；推理只读图像、长度和时间位置，不读真边界、文件身份或类别。先以密集五类CE为共同目标，全部时间位置输出；不要再捆绑教师KL、二分类修复损失或新门槛。是否加边界辅助目标留给之后的匹配消融。

所有模型直接产生完整概率/标签序列，按相同规则映射回原10Hz轴并 RLE；没有 Base P区间或单向A4C编辑。另保留在相同新概率上运行训练分区选定 B3 的解码控制，以区分表示收益与读出收益。

- 首轮 L/F/J-low/J-high 共享固定数据暴露计划与最终6000步调度，先各到2000步。默认头lr1e-3；J骨干lr候选1e-5、3e-5，warmup200、AdamW、梯度clip1。权重衰减/精度/有效batch与checkpointing在第一批真实FIT测量前固定在运行配置，不能看外层开发结果再修改。

以上是本次探索的实施上限与默认起点，不是用户声称过的数值承诺。正式队列前用真实FIT样本测量速度/显存并写一份完整 forecast；无需再向用户索取已授权训练的确认。若算力访问确实不可用，继续完成可运行准备并如实记录阻塞，不能报已开始训练。

## 7. 首轮具体执行合同（读出前固定）

以下条款解决计划审查中的具体问题，优先于前文的概述。它们只规定新实验，不修改任何历史结论。

**分区与输入足迹。** 分组/采样seed固定2026110257。内层约80/20按session分配，先仅用元数据确定并冻结清单；记录每类真实数量。FIT和inner-calibration的构造流必须**各自重建**，各自只使用本分区来源，禁止把旧full3364混合bank按chunk重新分配。所有64采样位置、四个16帧块、padding以及重叠推理窗口的完整帧来源都须通过本分区allowlist检查。身份留给sampler/auditor，不输入模型。

**精确时间单位。** 每条序列的64个10Hz采样位置按四个连续16帧块编码；tubelet2的第j个token覆盖本块位置[2j,2j+1]，时间中心2j+0.5。空间平均后展平为32个时间token；末块不足64时复制最后一张有效图像补齐，mask只标记原始有效位置。每个token的五类logits重复到所覆盖的两个采样位置；CE按所有有效原始位置归一化。因此tubelet跨类别变更时等价于两个真实标签的softtarget平均，padding不贡献训练。这里的密集标签仍由公开clipcode和构造配方派生，不是专家瞬时视图/可见性真值。L读取的是16帧块内已上下文化的token，不能被描述成严格单帧模型。

**拼接与预测。** 推理64位置chunk，stride32，起点0,32,...，不足部分按上条补齐。每个有效局部位置t的概率权重为min(t+1,64-t)，归一化重叠概率后在原10Hz完整轴argmax并RLE。起点、权重和padding不依赖真边界/来源身份；所有真实位置都必须恰好有可计分输出。L/F/J使用完全相同时间映射、chunk计划和最终评价器。原A08指标须从原缓存经相同既有任务评价入口重现，不改变其推理定义。

**首轮模型/优化。** 最终层空间平均固定；TCN采用通道投影到128、两阶段、每阶段6个kernel3/dilation1,2,4,8,16,32的残差时间层、dropout0.1，输出五类；两个阶段的有效位置CE等权平均。L只对同一token做五类线性读出。F/J的TCN/readout初始化、seed、预训练权重、head优化器、输入/标签/增强/精度及暴露计划相同；F关闭骨干梯度，J开启全部活跃视频编码路径的梯度。2.1中的图像专用分支或未选用的中间输出norm仍须严格载入并保留，但明确冻结/列出，不把结构性未使用参数的权重衰减冒充学习。若官方输出多层拼接，只按已确认的官方层次映射选最终归一化层，不猜测顺序或丢弃载入键。骨干dropout/drop-path按同一显式配置（首轮均为0），TCN训练时使用相同dropout策略。初始同一输入的F/J输出必须一致。无A08教师、二分类修复或新边界损失。

有效batch为2个64位置chunk，每步一条native和一条constructed；native按五类轮转抽样，constructed一半均匀起点、一半以训练真变更为中心（仅训练采样允许看标签）。把128个派生采样标签/64个token与真实来源/图像数量分开报告。AdamW beta(.9,.999),eps1e-8,weightdecay.05；headlr1e-3，J骨干1e-5/3e-5；全局clip1，warmup200后cosine至6000；BF16骨干与FP32损失，使用同一checkpointing策略。数据管线/新骨干来源与归一化合同通过后，先做有界真实FIT吞吐/可学习性检查。

**选择、读出与公平比较。** inner checkpoint cadence500步，正式固定表在2000/6000步。J学习率只在2000步inner-calibration选择：先最大multi segmentF1@50，同分先高native macro-F1，再少native A4C/A5C双向错误，再小骨干lr。单独保留J-low/J-high的2000步inner行；不能把选优包和一个任意配方之差全归因于结构。至少F和选定J继续到6000以获得等步数、等输入的主要对照（除工程/预算停止）。2000步外层开发表不决定该继续规则。每个模型另报从内层所选checkpoint的package行，不与等步数行混淆。默认不作温度缩放；B3附加控制若需要选参，只用预定原V01网格在inner-calibration选择并在相应外层读出前冻结。

初始四个pilot都到2000步，F/选定J到6000，然后**优先第二seed的匹配F/J**，其后才考虑128采样位置或多深度token；不能用外层反馈偷偷插入新arm。若之后开发观察确实启发新结构，另写预定探索阶段并披露适应性，不能称其为selection-independent验证。所有确认项是否完成按实测预算如实报告。

**完整forecast。** 正式运行前必须包含四个pilot、F/J续训、全部计划inner/development推理、冷启动/checks、缓存、checkpoint写入，以及至少2GPU小时收尾/完整评价储备；同时估计第二seed是否能完整放入。40GB峰值计入所有活动optimizer/模型/冻结特征cache以及原子写入共存。测量的必须是实际2x64输入/四块反传路径，而非一个短块的理想前向。真实不足时保留未完成确认项，不修改旧结果或拿缩减后的配方冒充原计划。
