## Training decision if qualified

Only after the above passes, freeze a complete matched training card before any model forward. Candidate is real operator-site spatial supervision versus coordinate-shuffled supervision on the same images, initialization, model, optimizer and compute. Before training, the final card must fix exact localization metrics, baseline inputs and numerical pass margin. Pretraining must beat fixed center/geometry-only controls on held-out public patient groups before downstream repair, so a center prior or artifact cannot be presented as anatomical evidence. Downstream retains original A31 source0 full Base-A4C runs/memberships and A44C600 plans, the same one-way weighted-mean scalar rule, and the same absolute complete-sequence/A5C/A4C/short/boundary gates as A47. No threshold/loss/gate/seed search. Independent per-case pairing and once-cache audit required. This paragraph is a candidate, not an activated training configuration.

If the direct data path is infeasible, an already released, explicitly licensed human anatomical-localization state may be inspected as an alternative only before a training card is fixed. No unlicensed code reuse or unsafe checkpoint unpickling, and no claim of A5C transfer before a matched result.
