# EV9V 互补证据与条件蒸馏任务书

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 检验 E0 与官方代码训练的 EchoViewCLIP 视频模型是否提供可实际利用的互补预测；只有固定融合确实改善完整系统，才训练单个 E1＋ASRF 学生模型继承收益。

**Architecture:** 教师固定为 E0 帧分类器和 B7 视频分类器，概率等权融合后接已有 B3。训练阶段保持 E1＋ASRF 架构不变，对比原监督与原监督加教师概率蒸馏；不引入新的 gate、注意力或边界结构。

**Tech Stack:** 当前 Python/PyTorch 环境、cache_v2、已冻结 EV9V protocol、现有 B3/ASRF 和联合微调脚本。README 英文，计划中文。

**状态：** 仅规划，尚未实现或执行。Claude 是预期执行方；先执行任务 1–2，只有任务 2 的固定启动条件满足才执行任务 3。无需为了得到结果重复请求批准，但不可越过停止条件。

- 第四轮报告记录：E0＋B3 和至少两个 E0＋ASRF 种子共同判错的 54 个参考段中，B7＋B3 也错 27 个，另外 27 个匹配正确。这是检查互补性的线索，不是融合有效的证明，也不是 27 个独立病例。
- 分半区看，B7 在 selection 的 32 个共同错误中仍错 21 个。必须报告两个方向的互补、新增错误和来源数量，不能只展示修复一侧。
- 上述统计比较了不同完整系统，差异可能来自识别、解码或两者。不能预先归因于动态结构、心动相位或局部解剖证据。
- 本轮新增输入是两个既有识别系统的预测。它不重开 M5、固定区间读出、阈值搜索、G1/G2 或监督对比路线。
- 只用 EV9V；不使用 Pediatric 数据、其派生缓存或适配权重，不等待其许可邮件再开始 EV9V 工作。不要下载新数据、接触 EV9V test、改标签或剔除难例。
- 两个验证半区都已参与开发，本轮仍属探索性。教师也见过训练库，教师在训练库的表现不能称为折外或泛化结果。
- 概率平均和知识蒸馏都是现成方法，不能仅因采用它们宣称论文创新。参考：[Hinton et al., Distilling the Knowledge in a Neural Network](https://arxiv.org/abs/1503.02531)。

## 任务 2：一个不训练的实际融合基线

- [ ] 固定每个时刻 `q = 0.5 * p_E0 + 0.5 * p_B7`，不搜索融合权重、温度、类别专用系数或额外后处理。
- [ ] 比较 E0＋B3、B7＋B3、q＋B3。三个系统使用同一份已有 B3 参数网格和相同 calibration 选择规则。原始冻结基线另列，不能被重选参数的对照行覆盖。
- [ ] 参数只在 calibration 选择：先要求 native macro-F1 >= 0.980、边界召回 >= 0.95，再最大化多段流 segment F1@50。同分按配置中预先固定的参数顺序。没有可行设置就报告不可行，不新增回退规则。
- [ ] 冻结参数后，对 selection 只应用一次，不查看其他参数在该半区的结果。所有系统报告原生五类 macro-F1、A4C/A5C 两向错误、segment F1@50、边界召回、内部额外切分及修好/新错的来源录像和 session。
- [ ] 按既有配对统计报告区间并明确构造流复用录像造成的依赖。教师和固定融合均是固定权重系统，不把三次解码当作三个训练种子。

**蒸馏启动条件，计算前固定：**

1. q＋B3 的多段流 segment F1@50 在两个半区都至少高于既定最强旧参照 **0.005**：selection 参照 0.9344097，calibration 参照 0.9721422；脚本使用原结果的全精度值。
2. 对任务 2 中每个在 calibration 找到可行设置的同预算单教师控制，q＋B3 在两个半区的 segment F1@50 都至少高 **0.005**。单教师在 calibration 没有可行设置时，明确标为不可行，不给它事后选回退参数；仍报告其原冻结系统。若两个单教师均无可行设置，则本轮不自动启动蒸馏，只报告融合的可行性变化。不能只因融合超过旧参照就认定新增教师有益。
3. 两个半区的边界召回均 >= 0.95；native macro-F1 分别 >= 0.973（selection）和 0.980（calibration）。
4. 逐来源的修好/新错清单与总指标一致，并完整报告提升是否集中于少数录像；不把大量重复片段解释为大量新病例。

四项满足才开训。这是计算资源分配门槛，不是“互补信息存在”的必要条件；失败只关闭本次等权融合与条件蒸馏方案，不证明其他融合无效。calibration 上 0.9739 的后续旧系统作为敏感性参照另列，不改原最终成功标准。

若未满足：完成英文报告、保留全部原始结果，然后停止；不转去搜索权重或训练 gate。任务 1 的标签知情选择不能作为可部署系统，不能替代任务 2 的真实结果。

- [ ] 阶段 2 通过后，先把训练 manifest、完整超参数和选择规则提交，再生成训练库的 q。教师始终冻结，标签来自原 EV9V；不以教师共识替换真值。
- [ ] 教师只对原训练库的 native windows 和固定训练流生成概率，流式滑窗规则与验证相同。不要按真实切面边界截断教师窗口。每个目标包含序列 id、实际帧/时间索引、有效长度、教师版本和哈希。
- [ ] 两组学生都是原 E1＋ASRF：C0 使用原监督损失；C1 使用完全相同的损失再加蒸馏。每个种子从相同 E1 和相同 ASRF 初始权重出发，训练最后一个 ViT block、ln_post、proj 和 ASRF；其余视觉层冻结。
- [ ] 固定三个种子 0/1/2。沿用第二轮每 epoch 375 updates、batch 8、backbone lr 1e-5、head lr 1e-4、weight decay 1e-4。两组都执行 10 epochs，使用最后权重；不早停、不按验证集挑 epoch。帧、序列、批次顺序、精度设置和更新次数逐种子配对。
- [ ] 原损失及其各项权重完全继承现有 ASRF 配方。唯一增量是最终分类输出（边界细化之前）上的 soft-label KL：`L_C1 = L_original + 0.5 * mean_valid KL(q || softmax(z_final))`，温度固定 1。padding 排除；序列归一化约定沿用原训练损失。教师不提供额外的边界真值，不增加边界蒸馏。
- [ ] 原监督损失与蒸馏项读取同一次学生前向结果；不能因蒸馏多跑一次含随机操作的前向而改变批次或随机状态配对。C0 通过同一路径将蒸馏系数设为 0。
- [ ] 冒烟检查：蒸馏权重为 0 时复现 C0 的同批损失与更新；q 与 logits 时间错位时拒绝训练；教师无梯度；冻结参数不变；蒸馏项给学生非零梯度。仅必要检查，不追加诊断训练网格。
- [ ] 两组都报告 ASRF 默认解码与同预算 B3 解码。decoder 选择仍只在 calibration 进行，selection 只应用冻结设置；默认与 B3 分开成行，不能逐半区挑不同系统合成一个赢家。

完成后同时比较：C1–C0、学生–融合教师、学生–原 ASRF/B3/B7，以及最强旧参照。蒸馏提升是一个要检验的结果，不能从教师提升直接推断学生会继承。

C1–C0 只隔离“加入这个 q 蒸馏目标”的效果，不能证明融合教师比单教师更适合蒸馏。当前不追加单教师蒸馏训练臂，也不据此宣称多教师机制的新颖性或必要性。
