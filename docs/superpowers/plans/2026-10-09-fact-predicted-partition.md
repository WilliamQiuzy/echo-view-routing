# FACT Predicted-Partition Training Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax. Claude is the executor. This is the lead's next task after the completed short-segment localisation report.

**Goal:** 检验可从输入预测的边界细分，是否比固定细分更能保留短段，并让完整系统接近或超过强基线。

**Architecture:** 冻结 E1 视觉编码器。先在训练集上训练一个小边界预测器，再冻结它；随后配对重训两组 FACT，全套时序参数都可训练。一组在最后 U 块使用固定均匀细分，一组使用预测边界细分。两组的其余结构、官方损失、初始化、数据和预算相同。参考边界只用于训练监督和评估，不能构造模型前向的分区。

**Tech Stack:** 现有 E1 缓存、官方 FACT GTEA、PyTorch、项目批次/恢复/评估工具、pytest、英文 README。

允许实现并运行本任务。准备、实现审查和冒烟检查通过，且预计总 GPU 用时不超过 **24 小时**，即可直接启动队列，不再请求一次开训确认。预算覆盖边界头训练、两组三种子的正式训练、GPU 检查和评估；CPU 工作另记。预计或实际超预算时保存进度并报告，不能靠缩短某一组或更换底座凑预算。

我们不是把上一轮诊断条件 B 改成可部署模型。诊断只说明给定参考位置可以恢复部分训练段。大部分损失在 i/u 块已经发生，所以这轮必须重新训练 **全部 FACT 时序部分**，观察 i/u 是否也改变；只对原权重换分区不能回答这项训练问题。

这也不同于以前的“单独学边界、冻结分类器命名区间”：此处边界只决定 FACT 内部的细分，标签仍由重新训练的 FACT 帧/token 分支产生。它仍是对已有 FACT 的扩展，不预先宣称创新或收益。

## 三个主系统

| 系统（英文报告名称） | U 块的分区 | 权重 |
|---|---|---|
| Original FACT | u 分支 argmax 的连续区间，官方规则 | 复用上一轮三个冻结最终模型；不重训 |
| Uniform-refinement FACT | 保留原区间边界，每个原区间从起点每 8 个样本细分 | 三个种子，正式重训 |
| Predicted-refinement FACT | 保留原区间边界，加边界预测器给出的内部切点 | 三个种子，正式重训 |

固定网格为 **8 个样本（0.8 s）**，不搜索其他粒度。它小于训练构造片段的最低长度 10，且是已固定“短段”16 样本口径的一半；这是事前确定的简单对照，不声称是最佳设置。原区间 `[s,e)` 加 `s+8,s+16,...` 且严格小于 e；长度不足 8 不增加切点。

原生窗口和构造流执行完全相同的前向规则。不能根据 is_native、文件名、参考段数或标签跳过切分。多出的内部区间不必成为输出切面段；最终标签仍按官方解码给出，再合并连续同类输出。

## 固定边界预测器

输入只有 **未经 FACT 内部遮挡的 E1 512 维逐帧特征**，不读原始图像、源编号、拼接位置、E1 分类概率或标签。在训练/推理中都是这条输入路径。FACT 自己的通道遮挡、时间遮挡和 dropout 保持原配置；不得事后把边界头移到另一种输入。

- 对每个 t，拼接 `[x_(t-1), x_t, x_t-x_(t-1)]`，得到 1,536 维输入。t=0 使用 x_0 作为前一个特征，但该位置不参与损失、也不能切。
- `Linear(1536,64) → ReLU → Conv1d(64,64,kernel=3,padding=1) → ReLU → Conv1d(64,1,kernel=1)`。无 dropout、归一化、残差或额外模块。每条序列先去填充再运行，不跨序列卷积。
- 训练目标 `z_t = 1[y_t != y_(t-1)]`。同切面拼接、原生窗口内的其他位置都是 0；本轮不用 `boundary_context.boundary_targets` 的弱负例权重，不使用 Gaussian 软目标。
- BCEWithLogitsLoss，pos_weight 为该种子 epoch-0 实际训练批次中有效负例数 / 正例数，固定后不再更新。排除 t=0 和 padding。每条序列先平均有效位置损失，再平均序列。没有正例或非有限权重时停止并报告。
- 三个种子各 **20 epoch × 375 次更新**，每次 4 条构造流 + 4 个原生窗口，与原批次生成器一致。AdamW lr=3e-4、wd=1e-4、clip=1；375 次 warm-up，之后 cosine 到 0；取第 7,500 次更新的最终权重。
- sigmoid 后用 **0.5 阈值、2 样本 NMS 半径**，位置 0 排除。复用 `non_max_suppression` 的固定峰值选择逻辑，平局按原有稳定排序；不扫阈值，不从开发集校准。
- 正式 FACT 训练前冻结头。两组同一种子使用同一份头；固定组不使用其输出构造分区。冻结头仅受自己的预训练监督，不接收 FACT 损失的梯度。报告它是独立训练、被冻结的边界模块。

边界头是本轮新增的模块。固定组虽然拥有同一份辅助训练产物，却不利用边界意见；这不是完全相同的有效容量对照。本轮检验的是两套明确的分区策略，不把差异归因于单独的注意力操作。

每个种子的头只训练一次，两组共用它，不为固定组另训一个。新组相对旧 FACT 增加了这 7,500 次边界监督更新；与旧 FACT/ASRF 的比较不是总训练计算完全相同的对照。表中同时报告 FACT 更新数、头更新数、两者耗时和部署所需参数。
