# EX1：同检查评估、检查上下文判定与选择性预测

2026-11-03 冻结于看到任何结果之前。负责人要求另开一条线，运行上一轮诊断里提出的实验。这条线与 A60 并行，但互不共用队列、命名空间和缓存写入。

## 1. 为什么做这轮

A08 之后的 50 多行实验没有稳定超过 A08。开发集片段分辨率约 0.002，A5C 分母只有 11 和 18。修 A5C 的 12 个实验臂都停在同一取舍水平上（修对率与误伤率之比中位 4.3，净赚要 13.7）。残差约 90% 是 A4C/A5C。评估用的拼接流有 575/581 个跨 session 接缝，类别均匀。

本轮不训练视觉模型，也不提出新的视觉架构。它问三个没有被回答过的问题。

| 编号 | 问题 | 前序记录 | 改变的条件 |
|---|---|---|---|
| E1 | A08 的成绩在真实检查的顺序和比例下还成立吗 | A26、A50 用拼接库；`docs/theory/risk_controlled_routing.md` 第 0 节第 2 条提议过，索引中未执行 | 流按同 session、序号 k 排列，整段录像，保留自然比例 |
| E2 | 同一次检查的其他录像能否帮助判定 | A42 只把同 session 配对用于训练损失；A14–A17 路由看局部窗口 | 推理时利用整次检查，不重训视觉模型 |
| E3 | 模型能否在不确定时拒判，并把错误率压住 | 索引中没有选择性或风险覆盖实验；A14–A17 是路由；H03 是历史设想 | 风险覆盖曲线、合并心尖类、跨数据集实际错误率 |

## 2. 数据范围

- **可用：** EV9V train 的类别标签和 B0 跨 session 留出输出，validation 的 selection/calibration 两半，A50 已缓存的 Dynamic、LVH、CAMUS 输出。
- **不读：** EV9V test 的标签和输出，包括 `predictions/ev9v`。Pediatric、Unity、隔离患者一律不读。代码里写断言。
- **隐私：** 录像和 session ID、逐例输出、权重留在服务器。公开文件只有聚合数字。
- **检查单位：** 沿用协议的 session（`video_id` 去掉最后的 `_k`）。session 未确认是患者。bootstrap 按时间戳整簇重采样。495 个时间戳没有跨划分，有 96 个时间戳含多个 session，所以这样更保守。
- **采集顺序：** 用 k 升序。已验证的证据是同视图相邻占 32–41%，随机重排只有 16–22%，视图平均位置呈 PLAX→PSAX→A4C→SC4C。这是间接证据，不是采集时间。

## 3. E1：同检查基准

每半 36 条流，只含五类录像，整段、10 Hz、无 gamma。共用完全相同的录像，三种排列如下。

| 流 | 排列 | 用来回答 |
|---|---|---|
| X-exam | 同 session，k 升序 | 真实顺序下的表现 |
| X-shuffled | 同 session，固定随机序 | 顺序本身的贡献 |
| X-rewired | 同一半内重新分配，所有接缝跨 session，长度结构不变 | 同 session 接缝的贡献 |

A08 s0/s1/s2 真实跨接缝前向，步长 5。解码用 raw argmax 和各 seed 原有 B3，不重调。指标是合并计数的片段 F1@50、变化点 P/R（10 位置内）、短段 ≤10/≤16 的 FN/FP、帧准确率、A4C↔A5C 帧混淆，以及把 A4C/A5C 合并后的片段 F1。配对 5000 次时间戳整簇 bootstrap，种子 2026110399。

**流水线校验（不通过就停）：** 用同一指标代码重算缓存的 A08-s0+B3，必须得到 multi 片段 F1 .956349/.982692 和原生 macroF1 .978591/.992942。新前向跑原生录像，必须和缓存概率一致（最大差 ≤1e-3）。

E1 是描述性结果，没有胜负线。外部模型（EVC、STFM、ASFormer）在 A08 结果之后再接，能复用现有适配器才做，否则如实写未做。

## 4. E2：检查上下文判定

证据 `L_i(c)` 是录像 i 单独前向后 log p(c) 在位置上的均值，所以不含其他录像的像素。

| 臂 | 用到的信息 | 作用 |
|---|---|---|
| B | 只看本录像，argmax L | 基线 |
| P | 温度 τ + 全局类别先验 | 校准对照，不含检查信息 |
| S | 随机序的转移链 | 只含检查的类别构成 |
| T | k 序的转移链 | 构成 + 采集顺序 |
| O0 | A4C/A5C 差值 d 的高斯判别，无偏移 | 校准对照 |
| O | 同上，加检查级随机偏移 b | 检查内对比 |
| OT | O + k 序转移链 | 完整模型 |

T/S/P 由条件对数似然在固定网格 τ∈{.25,.5,1,2,4,8,16,32} 上选 τ。转移计数加 1 平滑。O 系列只在 B 判为 A4C/A5C 的录像上枚举标签，其余固定。参数 (μ4, μ5, σ4, σ5, τ_b) 用已知标签的边际似然拟合，O0 固定 τ_b=0。录像超过 14 段时改用从 B 开始的坐标上升，并报告次数。

**两个数据集，参数都来自独立 session。**

- **D1（检验原理，样本量大）：** 三个 B0 对 3364 段训练录像（502 session）的留出输出。参数取另外两折，解码第三折。B0 比 A08 弱很多，所以 D1 只回答检查里有没有可用信息。
- **D2（目标模型，样本量小）：** A08 s0/s1/s2 在开发集的原生输出。转移表来自 train 标签。其余参数从另一半拟合。

**事先写定的判停线。**

1. 在 D1 上，T、O、OT 至少一个臂同时满足：净修复（修对 − 误伤）> 0，且相对 B 的 macroF1 差值 95% 区间下界 > 0。否则这条路线结束。
2. 只有第 1 条通过才看对照：T−P、T−S、O−O0 用来说明增益来自校准、构成、顺序还是对比。
3. 在 D2 上逐 seed、逐半报告计数。分母太小，不声称显著。任一通过 D1 的臂若在 D2 的 6 个单元中净修复总和 < 0，就不推荐部署。
4. 不开 EV9V test。是否用历史 test 做一次读出，由负责人决定。

已知录像边界时片段问题消失，所以另报 X-exam 上"已知边界 + 逐录像判定"的片段 F1，作为存档路由场景的参考。这行不和连续流比高下。

## 5. E3：选择性预测

录像级置信度由窗口 softmax 的均值 p̄ 得到，用 max p̄。判定口径有五类和合并心尖类两种。

1. 在一半上选最大覆盖、经验风险 ≤α 的阈值，α∈{1%,2%,5%}，在另一半上报告实际风险和覆盖率。
2. 用全部开发集选阈值，在 Dynamic A4C、LVH PLAX、CAMUS 上报告实际风险和覆盖率。这是真正没有参与过 A08 训练的外部数据。
3. 同时报告各去向的错误占比（被判到某类的录像里错了多少）。
4. **范围外录像：** validation 的 PMPALA 录像不属于五类，真实检查里却存在。前向后报告它们被各阈值放行的比例。
5. 这是经验曲线，不是有限样本保证。理论表要求的样本量超过现有开发集，报告里写明。

## 7. 证据边界

结果都来自反复使用的开发数据或训练集留出折。session 不是确认患者。k 序是采集顺序的间接证据。标签是公开标签，没有独立读片。B0 上的结论不能直接搬到 A08。T 学到的顺序来自这个中心的习惯，换中心未必成立。本轮不声称临床验证，也不声称达到论文目标。

## 8. 读结果之前的补充（独立代码审查后）

以下改动都在读取任何 E1–E3 指标之前写定。

1. **X-rewired 只作描述。** 每个 session 的录像被打散到多条流，按流重采样的区间会偏窄，所以不报区间。改为 3 次独立重连（种子 2026110399、+1、+2），报告点估计和次间差异。
2. **对照的读取时机。** T−P、T−S、O−O0 只在判停线第 1 条通过时才写入单独文件。
3. **新增的探索项（事先声明，不计入判停线）。** S−P、OT−T、OT−O 三个对照，以及 session 内与跨 session 的 AUC 诊断。AUC 无论判停线结果都报告，因为它说明检查内对比有没有信号。
4. **前向核验。** 三个 seed 的权重都核对 `models_frozen` 清单里的 SHA256，三个 seed 都做前向一致性检查。
5. **额外报告。** O 系列枚举时混入的真值非心尖录像数；走坐标上升的 session 和录像数，以及去掉这些 session 后的结果；S 臂 5 次随机序的波动；高斯拟合是否收敛；跨折时间戳数；D1/D2 上原有录像规则（位置多数投票）的 macroF1，以便和 B 区分；外部数据和跨半结果的 95% 单侧 Clopper-Pearson 上界，以及外部数据各去向的错误占比。
6. **EV9V test 的边界。** 外部清单 JSON 含 EV9V test 段，整文件解析后只保留 Dynamic、LVH、CAMUS 三段。主清单 CSV 逐行过滤，test 行不进入任何计算。写探查脚本时曾打印过两条去 ID 的 test 标签值（无法对应到录像，未用于任何分析）和 10 个训练集 session ID，写入这里留痕。
7. **GPU 繁忙时等待，** 每分钟查一次，最多等 30 分钟。前向累计墙钟超过 0.5 小时就停，只保留已完成部分。
8. **资源调整（读结果之前）。** 盒子上其他任务把负载推到 15，前向慢于预估。额外两次重连只跑 s0，次间差异也只在 s0 上看。预计前向总占用约 0.55–0.6 小时，略超 0.5 小时自限，超出部分写入 `resources.json`。
9. **操作失误留痕。** 跑覆盖率时覆盖了服务器项目根目录原有的 `.coverage`（可重新生成的测试产物）。
