# Short-segment discriminators: pair-conditional thresholds (post-hoc decision calibration check)

> 来源：项目负责人 2026-10-07 在冻结迁移检查结束后的决定（原文照录）。执行配置为
> `configs/experiments/short_segment_pair_threshold_v1.yaml`，在计算任何新阈值之前提交；新阈值在应用到两个验证半区之前提交。

**我的决定：Q0/Q1 暂不接入系统，也不扩大模型。先补一个针对关键类别的决策对照：按 A4C/A5C 的保留率选择阈值，而不是按所有类别的总体保留率。**

这次有一个明确发现：**总体指标达标，可以同时严重损伤我们最关心的类别。**

以种子 0 为例，132 个正确候选中，只有 13 个属于 A4C/A5C。即使删掉其中 6 个，总体保留率仍超过 95%。因此，原来的阈值选择目标本身就允许丢掉接近一半的正确 A4C/A5C 段。这个问题在此前的任务设计里没有处理充分。

另一方面，A4C/A5C 内部的 AUC 为 0.88–0.95，说明分数存在一定排序能力，**但不能保证换一个工作点就能同时保住正确段、删除错误段。** 这正是下一步要检查的事情。

下面可以直接给 Claude：

---

**任务：冻结 Q0/Q1，检查类别对条件阈值。明确标为事后决策校准检查。**

**1. 所有模型和候选保持不变。**

使用已经保存的六个判别器、原候选生成器和原特征。不得重新训练、重新选 C、扩大 κ/λ 范围或改变公开标签。

保留当前报告及其结论，另建结果目录。

**2. 比较两个事先固定的决策规则，不扫阈值网格。**

- **原规则：** 使用原来按全部正确候选选择的阈值。
- **类别对规则：** 对预测类别对为 A4C/A5C 的候选，单独使用一个阈值；其他类别对继续使用原阈值。

新阈值只在**训练库内部的 calibration 部分**计算：取能够保留至少 95% 正确 A4C/A5C 候选的最高阈值。两种方向合并，即 A4C→A5C→A4C 和 A5C→A4C→A5C，共用一个阈值，避免继续细分少量样本。

Q0、Q1 分别按同一规则计算。不能利用原 EV9V 的两个验证半区重新选择阈值。

推理时，是否使用新阈值只能由**预测的类别对**决定，不能读取参考标签。

**3. 冻结阈值后，重新应用一次。**

先提交配置和新阈值，再在两个原验证半区上应用。报告每个种子、每个半区的：

- 正确 A4C/A5C 段保留及误删数量；
- 错误 A4C/A5C 段删除及放过数量；
- 相对原规则，救回了哪些正确段，同时放过了哪些错误段；
- 来源录像和 session 去重计数。

同时报告训练库内部 calibration 的样本数。样本少时，经验保留率达到 95% 可能意味着全部保留，不能据此声称真实保留率有保证。

参考标签无法归入二分类的候选仍单独计数，不因本次检查而被当成“安全可删除”的候选。暂不执行真正的删除、合并或完整系统修改。

**4. 判定目的要写清楚。**

沿用本轮已固定的实际价值标准及汇总方式，检查 A4C/A5C 能否同时达到保留率 ≥0.90、错误段删除率 ≥0.50。报告完整计数，不只报告是否过线。

- **若条件阈值使同一个判别器达到要求：** 支持“当前工作点不合适”这一解释。再制定完整系统实验，确认局部收益能否传到 segment F1，不能直接宣布超过基线。
- **若保住正确段后，错误段几乎都被放过：** 当前分数没有提供需要的取舍。这两个判别器的阈值检查结束，不再搜索更多阈值。
- **Q1 与 Q0 的比较：** 必须在两者都采用类别对规则后进行，不能把阈值规则变化归因于视觉特征。

这仍然是反复使用开发集的探索性检查。最终系统目标、test 访问限制和真实扫查证据的要求均不变。

---

**这一步要区分的是“分数分不开”与“决策规则没有保护关键类别”。** 在区分之前继续训练更大的 Q1，依据不足；如果简单决策校准就有效，也应先把它作为强对照保留下来。

## 执行时固定的实现选择（配置中逐条记录）

- 模型与候选：短段迁移检查保存的六个管线，sha256 由 `rebuild.json` 记录并逐个核对。验证候选用原生成器重新生成，必须与服务器上保存的候选列表完全一致（配置固定其 sha256）。原规则必须逐项复现迁移检查的合并计数。
- 类别对规则：只看预测（解码）的类别对。A4C→A5C→A4C 与 A5C→A4C→A5C 共用一个阈值，其他类别对用原 0.95 阈值。
- 新阈值：在原训练库的 calibration 部分，取预测类别对为 A4C/A5C 的正确候选，用探针原来的规则（`scripts.short_segment_probe.threshold_for`）取能保留至少 95% 的最高阈值。每个种子、Q0 与 Q1 各自计算。少于 20 个候选时，这等于全部保留。每个阈值都报告背后的 calibration 计数、经验保留率和单侧 95% 下界。
- 补充结果（不参与判定）：训练库 held-out 部分在两种规则下的 A4C/A5C 保留与删除。
- 报告：每个种子、每个半区及两个半区合并，两种规则下的正确 A4C/A5C 保留/误删、错误 A4C/A5C 删除/放过，以及录像与 session 的去重计数。相对原规则，决定发生变化的候选（救回、丢失、放过、新删）给出去重计数，并给出不含 id 的逐条列表（正确段用病例编号）。二分类之外的候选单独计数，不当作可安全删除的候选。
- 判定（沿用迁移检查的实际价值标准与汇总方式：每个种子两个半区合并，“多数种子”指至少 2/3）：
  - 达到要求：多数种子中，同一种子内 A4C/A5C 保留率 ≥ 0.90 且删除率 ≥ 0.50；
  - 保住正确段但放过错误段：未达到要求，但多数种子中保留率 ≥ 0.90 而删除率 < 0.50；
  - 保留率未达到：其余情况；
  - 有模型达到要求 → 支持“当前工作点不合适”，下一步制定完整系统实验（本次不做，也不宣称超过基线）；没有模型达到要求 → 这两个判别器的阈值检查结束，不再尝试其他阈值。
- Q1 与 Q0 的比较只在两者都用类别对规则时进行：Q1 − Q0 的 A4C/A5C 与总体保留率、删除率，配对 bootstrap 的单位与迁移检查相同。
- 这些阈值是执行者为把任务书的定性分支变成可检查规则而定的；数值随全部原始计数一起报告，负责人可以按自己的标准重新解读。
