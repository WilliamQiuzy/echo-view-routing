# Short-segment discriminators: frozen transfer check

> 来源：项目负责人 2026-10-07 在短段判别实验结束后的决定（原文照录）。执行配置为
> `configs/experiments/short_segment_transfer_v1.yaml`，在建立任何验证候选、计算任何验证结果之前提交。

**这轮可以结束，但结论应是“当前实验没有支持增加视觉特征”，不能据此关闭所有段级学习方法。下一步我建议冻结 Q0/Q1，做一次迁移检查，不扩大模型。**

我核对了报告和实现（`docs/results/2026-10-07_short_segment_probe/README.md`）。这次实验有三个问题：

- **总体成绩掩盖了关键类别。** Q0 总体保留约 98% 的正确段，但 A4C/A5C 只保留了约 73%–80%。对我们关心的问题，它并没有接近满分。
- **正确与错误候选的来源不对称。** 正确段全部来自拼接流，错误段多数来自原生录像；长度、置信度和增强也不同。这些差异可能让任务变得容易，但目前没有证明哪项造成了高分。
- **类别组成也不同。** Q0 的输入包含类别对。正确候选涵盖很多类别对，错误候选却集中在 A4C/A5C。因此总体 AUC 不能替代同一类别对内部的比较。

我上一份任务书没有把关键类别对和候选来源的覆盖要求写充分，却设置了一个可能被天花板挡住的优越性门槛。这是设计上的不足，不能用换一个更复杂的 Q1 来补救。

**下一步先回答一个更直接的问题：Q0 的简单规律，离开这些编码器训练录像以后，还管不管用？**

## 任务：冻结短段判别器，检查它们在原验证录像上的表现

只做推理性检查，不接入完整系统。

**1. 固定模型与阈值。**

保留 Q0、Q1 的标准化参数、分类器、已选 C 和原来的主工作点阈值，不重新选择。

当前脚本没有保存拟合后的分类器。请按已提交代码、原训练库和已选 C 重建并保存；先复现原报告的指标及阈值。不要重新做超参数搜索。报告中说明这是重建已有模型，不是新增候选训练。

**2. 使用原先固定的两个 validation banks。**

沿用 J0、κ=8 生成候选，保持特征定义、类别规则和输入处理完全一致。两个半区都不用于重新定阈值。

这些录像没有参与此次判别器拟合，但它们已经被项目反复用于开发，E1 的历史选点也涉及原验证集。因此只能称为**开发集迁移检查**，不能称为独立验证或未见患者泛化。test 继续封存。

**3. 主表优先报告 A4C/A5C。**

每个种子、每个半区分别列出：

- 正确 A4C/A5C 段：保留多少、误删多少；
- 错误 A4C/A5C 段：识别出多少、漏掉多少；
- 其他类别对：单独报告；
- 无法归入二分类的候选：数量和比例，不悄悄排除后宣称覆盖全部错误；
- 每项涉及的来源录像与 session 数量。

总体 AUC 作为辅助结果。**主工作点继续使用原阈值，不在新数据上寻找“保留率刚好 95%”的阈值。**

**4. 把来源差异作为诊断，不作为筛选赢家的工具。**

分别查看原生录像、构造流、同切面跨录像拼接，以及长度相近的候选。拼接对照必须核实两侧参考切面相同，不能仅凭“附近存在录像拼接”就称为同切面对照。

如果某个子集太小，就报告数量与不确定性，不通过重复拼接凑出更多“独立病例”。

**5. 根据结果决定下一步。**

- **Q0 总体仍高，但继续误删 A4C/A5C：** 它不适合解决当前关键问题，不接入系统。
- **Q0、Q1 都明显失效：** 当前训练库的高分没有迁移；停止这两个判别器。下一步应重新设计训练数据与监督，不能直接加大 Q1。
- **Q0 有实际价值、Q1 没有额外价值：** 优先考虑简单 Q0 的完整系统实验，不为了创新强行保留视觉模块。
- **Q1 出现额外价值：** 先按独立来源检查收益，再制定完整系统比较。此次检查本身不证明超过 B3 或 ASRF。

另有一处记录需要收窄：**内层交叉验证按构造流分组，仍可能让重复使用的来源录像跨折。** 外层 session 留出没有因此失效，但内层选 C 的表现可能偏乐观。先如实记录，不为了本次迁移检查重新选 C。

目前最需要避免的是：把“容易的候选库上没有增益”解释成“视觉信息没有用”，或把 Q0 的近满分直接解释成“已经解决问题”。这次冻结迁移检查能更直接地判断，现有判别器是否值得继续使用。

## 执行时固定的实现选择（配置中逐条记录）

- 重建：每个种子、每个模型用原已选 C 在原训练部分直接拟合（不搜索）；必须复现原 0.95 / 0.90 阈值（误差 ≤1e-9）、留出 AUC（≤1e-12）和全部留出保留/删除率；拟合后的管线保存在服务器并记录 sha256。
- 输入：验证序列的 L1 概率和 fp16 特征取自 B_s{k} 缓存，与训练库的输入处理相同。
- 主工作点：原 0.95 阈值；0.90 阈值作次要结果。都不在验证数据上重新选择。
- 同切面拼接：中间段前后 5 个样本内的每个录像拼接两侧参考切面都相同，才算同切面；否则记为切面变化处的拼接。
- 二分类之外的候选按原因分开：两侧不是外侧类、中间有第三类、只是某个中间类参考单元的一部分（IoU < 0.5）、中间段内参考切面发生变化。
- 判定（每个种子两个半区合并，“多数种子”指至少 2/3）：
  - 失效：多数种子中 AUC < 0.80，或总体保留率 < 0.90，或总体删除率 < 0.50；
  - Q0 有实际价值：多数种子中总体保留率 ≥ 0.90、删除率 ≥ 0.50，且 A4C/A5C 保留率 ≥ 0.90、删除率 ≥ 0.50；
  - Q0 总体仍高但误删 A4C/A5C：多数种子中 AUC ≥ 0.95、总体保留率 ≥ 0.95、删除率 ≥ 0.80，而 A4C/A5C 保留率 < 0.90；
  - Q1 有额外价值：三个种子中 Q1−Q0 的总体删除率区间都在零以上，Q1 总体保留率不比 Q0 低 2 个百分点以上，且 A4C/A5C 删除率差值不为负；
  - 顺序：两者都失效 → Q1 有额外价值 → Q0 有实际价值 → Q0 总体高但误删 A4C/A5C → 都不满足。
- 这些阈值是执行者为把任务书的定性分支变成可检查规则而定的；数值随全部原始计数一起报告，负责人可以按自己的标准重新解读。
