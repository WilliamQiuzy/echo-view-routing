# Joint boundary decoding Implementation Plan

> 来源：项目负责人 2026-10-07 在 L1＋ASRF 一轮结束后的决定（原文照录）。执行配置为
> `configs/experiments/joint_boundary_decoding_v1.yaml`，其中固定了概率裁剪、并列解处理、网格顺序、逐种子
> calibration 选参和“稳定优于”的判定，均在计算任何本轮指标之前提交。

## 决定和依据

我核对了这轮的 README 和结果（`docs/results/2026-10-07_l1_asrf_integration/README.md`）。**同意结束 L1＋ASRF 这条组合路线。下一步值得检验的是：能否让视觉分类证据和边界证据共同决定分段，而不是先切段、投票，再把同类段合并。** 先用现有预测做一次小实验，不再直接启动六次训练。

这轮有三条真正影响下一步的证据：

- **视觉识别并非全部失效。** L1＋B3 在 selection 上读对了全部 11 段 A5C；ASRF 却把其中两段改成 A4C，还把一段 A4C 改成 A5C。这是实际观察到的退步，但病例少，不能扩大为普遍结论。
- **部分切换已经被边界头发现，最后却消失了。** 三个种子分别有 14、10、13 个切换附近存在候选切点，最终输出却把两侧判成同类并合并。这支持检查“边界和类别怎样共同决策”，不支持继续一味加强边界检测。
- **问题也不只属于 ASRF。** 视觉头判对的片段，接 B3 后仍有一部分无法匹配参考段。因此不能说“换掉 ASRF 的分类头就能解决”。第三轮已经试过类似替换，也没有成功。

## 任务：检验边界证据参与联合解码，能否减少正确视觉证据在完整系统中的损失

**1. 固定已有模型和输入。**

保留旧输入路径的 **224×224** 图像。冻结三个 L1 模型及本轮对应的 B＋ASRF。只读取 L1 的逐时刻五类概率和 ASRF 的逐时刻边界概率，不训练编码器、不训练新分类头、不更改公开标签。

这里不假设 L1 的输出一定正确，也不承诺最终标签不会改变。

**2. 比较两个明确的解码器。**

| 方法 | 如何决定最终标签序列 |
|---|---|
| J0：固定切换代价 | 使用 L1 分类概率；每增加一次类别切换，付出相同代价。相当于一个简单的 HMM/Viterbi 对照。 |
| J1：边界条件切换代价 | 使用完全相同的 L1 分类概率；ASRF 边界证据强时允许更容易切换，证据弱时更倾向保持同类。 |

两者都一次性寻找整条序列的最佳标签路径。**J1 不先把边界概率阈值化成固定区间，也不先投票后合并。**

这一点与第三轮不同：第三轮是“先确定区间，再给区间命名”。本轮让“在哪里切”和“两侧是什么类别”同时参与决策。

可以使用以下明确目标，避免临时添加模块：

\[
\sum_t \log p_t(y_t)
+\lambda\sum_{t>1}
\left[c_t\log b_t+(1-c_t)\log(1-b_t)\right]
-\kappa\sum_{t>1}c_t
\]

其中，\(p_t\) 是 L1 分类概率，\(b_t\) 是 ASRF 边界概率，\(c_t=1\) 表示相邻标签不同。J0 令 \(\lambda=0\)，J1 加入边界项。概率裁剪规则和并列解处理事先固定。

**3. 选参和对照必须约束住。**

先提交配置，再计算本轮指标。固定一个小网格，例如：

- \(\lambda\)：0、0.25、0.5、1、2；
- \(\kappa\)：0、1、2、4、8。

只在 calibration 上选参，沿用 native macro-F1 ≥0.980、边界召回 ≥0.95 的约束，再最大化 segment F1@50。没有可行配置就报告失败，不另设回退赢家。冻结后在 selection 上应用一次。

同时报告原 L1＋B3、B＋ASRF 和历史最强配置。**J1 必须优于 J0，才能支持“边界信息有额外作用”；仅优于 ASRF 不够。** 如果选中 \(\lambda=0\)，就不能声称边界项有效。

实现检查至少包括：短序列穷举与动态规划结果一致、\(\lambda=0\) 精确复现 J0、边界概率与标签切换位置对齐。推理时不能读取来源录像分界或参考标签。

**4. 重点回答三个问题，然后结束这一轮。**

- 那三段被 ASRF 改错的原生录像，修好多少，又新错多少？
- 原来有候选却被合并的切换，找回多少，同时增加多少错误切换？
- 完整系统是否超过 J0、L1＋B3 和原最强配置，并达到原有的 `.944/.982` 目标及分类、召回下限？

全部按来源录像和 session 去重。保留既有统计口径，并说明两个半区已反复用于开发。

如果 J1 没有稳定优于 J0 和 L1＋B3，这条联合解码路线也结束，不追加网格或网络。若有增益但未达最终目标，就报告局部收益，下一步再据此决定是否值得训练。

**这不是已经成立的新模型贡献。** ASRF 本身就使用分类与边界两条分支来细化输出；我们要检验的是另一种结合方式，而不是把两个分支重新命名。（ASRF 原论文：Ishikawa et al., WACV 2021。）

## 执行时固定的实现选择（配置中逐条记录）

- 概率裁剪：p 裁到 [1e-6, 1]，b 裁到 [1e-6, 1 − 1e-6]，float64 计算；首个样本没有转移项。
- 并列解：同分时保持不切换；同分前驱和同分终止状态取最小类别编号。
- 网格顺序：λ 升序、再 κ 升序；选参同分时取顺序靠前者，因此 J1 只有在严格优于全部 λ=0 设置时才会选中 λ>0。
- 逐种子在 calibration 上分别选 J0（λ=0 一行）和 J1（全部 25 个设置）；选参结果提交后才构建 selection 半区。
- “稳定优于”：selection 上三个种子的 segment F1@50 区间都在零以上，且 calibration 上没有种子的区间在零以下。
- 边界对齐：ASRF 的边界目标在 labels[t] ≠ labels[t−1] 的 t 处为 1，官方解码在被接受的峰值 t 处开始新段，因此 b_t 与 c_t 同下标。
